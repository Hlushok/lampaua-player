# UA Player 2.0.3

UA Player 2.0.3 updates and stabilizes the complete player core while retaining
the UA Player interface and LAMPA/LampaUA integration.

## Changes

- updated the complete playback, subtitle, settings, playlist, recovery,
  Watch Together, skip-segment and device-interface core;
- preserved subtitle track identifiers and declared languages when a legacy
  LampaUA JSON playlist is converted to the standard player playlist contract;
- retained Ukrainian as the only automatic-translation target while allowing
  any selected source language;
- restored the series title as the initial query for manual subtitle search;
- kept the compact finish-time label visible on phones and televisions;
- fixed Google TV detection and the TV header control layout;
- retained UA Player branding, update compatibility and the existing Android
  package identity.

Package: `com.lampaua.player`

Version: `2.0.3` (`versionCode 23`)

Minimum Android version: Android 6.0
