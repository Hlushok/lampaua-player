# UA Player 2.0.8

- Додано підтримку `ask_resume` у Playlist API: запит «Продовжити / Спочатку» при відкритті відео або ручному виборі серії зі списку.
- Автоматичний перехід до наступної серії починає її з нуля, зокрема після пропуску фінальних титрів. Зміна якості, озвучення й відновлення плеєра не викликають повторного запиту.
- Додано точні позиції, межі кліпів та інтервали звітів у мілісекундах зі збереженням секундного API.
- Покращено відновлення сесій після обертання екрана й перезапуску процесу; старі журнали перегляду переносяться зі збереженням історії та вибраних джерел.
- Додано захист від некоректних числових значень і переповнення часу при передаванні даних двигуну.
- Збережено дизайн UA Player, налаштування, український автопереклад, старі формати запуску LAMPA/LampaUA та сумісність підпису.

Пакет: `com.lampaua.player`. Версія **2.0.8**, збірка **28**.
Один APK для **arm64-v8a / armeabi-v7a**. Підтримка `ask_resume` і нових часових ключів залежить від їх передавання застосунком, який запускає плеєр.

Перевірено автоматичними тестами, lint та перевіркою APK. Реальне відтворення на конкретному телефоні або TV цими перевірками не підтверджується.
