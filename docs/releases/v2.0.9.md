# UA Player 2.0.9

- Додано відкриття M3U-плейлистів із TorrServe, зокрема кнопок «Плейлист» і «Продовжити».
- Повний URL із `fromlast` передається серверу без змін; отриманий порядок серій та їхні назви зберігаються.
- Елементи M3U відкриваються через наявний механізм плейлистів UA Player. Підтримуються відносні посилання.
- HLS-потоки відрізняються від списків серій і передаються стандартному механізму відтворення.
- Завантаження плейлиста виконується у фоні, зі скасуванням застарілих запитів та захистом від надмірного розміру. Облікові заголовки не переносяться на інший сервер.
- Збережено дизайн, налаштування, український автопереклад, старі формати запуску та сумісний підпис.

Пакет: `com.lampaua.player`. Версія **2.0.9**, збірка **29**.
Один APK для **arm64-v8a / armeabi-v7a**.

Підтримку перевіряють автоматичні тести, зокрема локальний HTTP-стенд без реальних торрентів. Реальний запуск із конкретним TorrServe на телефоні чи TV потребує окремої перевірки.
