# UA Player 2.0.1

UA Player 2.0.1 synchronizes the Android player core with stable Just+ v1.4.7
while retaining the UA Player interface, package, LAMPA/LampaUA integration,
Watch Together, playlists, server skip segments, session recovery, and
Ukrainian-only automatic subtitle translation target.

## Changes

- updated the Media3 playback stack and bundled video/audio decoders;
- made remote-control seeking follow decoded frames and added TV EXIT handling;
- fixed bottom control geometry, scrims, and the optional compact transfer line;
- made decoded surround sound the safe default, with optional Dolby/DTS
  pass-through for compatible receivers;
- improved audio-route recovery after pause, seek, and return from background;
- kept LAMPA playlist positions isolated from the standalone resume item;
- reset completed standalone videos to the beginning for the next launch;
- restored edge-aware TV focus navigation and durable phone screen locking;
- restored device auto-rotate after every picker return, including cancellation
  and process restart;
- kept working TV decoders alive across long pauses and stalled network ranges;
- allowed patient bounded waits for connected torrent/range sources before
  declaring playback stalled;
- added bounded decoder, Dolby Vision, lower-quality, live-window, and frozen
  picture recovery;
- treated meaningful progress from USB, SAF, and mounted local sources as active
  loading instead of a corrupt-file timeout;
- expanded the local sanitized playback trace without adding telemetry or
  automatic diagnostic uploads;
- preserved complete subtitle search, secondary subtitles, synchronization,
  appearance settings, and translation from any supported source language to
  Ukrainian.
