# UA Player 2.0.4

UA Player 2.0.4 contains two focused compatibility and launcher corrections.

## Changes

- added clear recovery guidance when an incompatible multichannel audio output
  prevents playback from starting;
- corrected the launcher icon on Android and Google TV so the round UA Player
  logo no longer appears inside an unintended square background;
- retained the UA Player interface, LAMPA/LampaUA integration, package identity
  and update-compatible signing contract.

Package: `com.lampaua.player`

Version: `2.0.4` (`versionCode 24`)

Minimum Android version: Android 6.0
