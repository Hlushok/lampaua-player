# UA Player 2.0.10

- Виправлено завантаження субтитрів: порожні та недокачані результати відхиляються, пошук переходить до наступного джерела. Один файл завантажується не довше 8 секунд.
- Історія перегляду зберігає до 1000 файлів. Різні назви й варіанти адреси того самого файла TorrServer використовують спільну позицію.
- M3U-плейлисти відновлюють позицію конкретного файла зі збереженням порядку серій, який повернув TorrServer через `fromlast`.
- Збереження прогресу із зовнішніх застосунків враховує початок кліпу. Явно передана позиція, включно з нулем, має пріоритет; непереглянуті серії не записуються в історію.
- На TV закриття списку повертає фокус на кнопку, яка його відкрила. «Назад» із підменю «Ще» повертає до відповідного рядка меню.
- Закриття вікна у фоні чи відкриття нового відео не повертає старі елементи керування поверх нового екрана.

Пакет: `com.lampaua.player`. Версія **2.0.10**, збірка **30**.
Один APK для **arm64-v8a / armeabi-v7a**, зі збереженням сумісного підпису.

Зміни перевірені автоматичними тестами. Перевірка на фізичному телефоні та TV залишається окремим етапом.
