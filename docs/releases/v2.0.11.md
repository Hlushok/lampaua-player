# UA Player 2.0.11

- Повернення прогресу після виходу кнопкою «Назад», включно з раніше встановленими версіями LampaUA на JSON-протоколі.
- Періодичні звіти мають тип `interval`; однакові звіти після згортання та відновлення сесії не надсилаються повторно. Непереглянуті серії залишаються непереглянутими.
- Кнопка пропуску не перезапускає анімацію на кожному опитуванні. Відкриття панелі керування та повторний пропуск не успадковують старий таймер приховування.
- Зовнішні текстові субтитри з плейлистів і сторонніх застосунків нормалізуються до UTF-8, зокрема Windows-1251 та UTF-16. Підтримуються HTTP-заголовки як парами, так і рядками `Name: value`.
- Ідентифікатори аудіо- та субтитрових доріжок не переходять на інший файл; мовні налаштування зберігаються.
- Для тунельного передавання стисненого звуку перемотування зберігає відкритий аудіовихід, якщо конфігурація не змінилася. Для інших режимів залишається звичайне очищення виходу.
- Перед встановленням оновлення перевіряються розмір, SHA-256, пакет, версія та сертифікат APK. Неповні й невідповідні файли відхиляються.

Пакет: `com.lampaua.player`. Версія **2.0.11**, збірка **31**.

Для нового callback-протоколу потрібна відповідна зміна LampaUA. Старий JSON-протокол також підтримується. Перевірка на Android-емуляторі не замінює перевірки Redmi Note 12 та фізичного TV з HDMI/тунельним звуком.
