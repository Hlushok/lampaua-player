# UA Player 2.0.6

- Повернуто головну сторінку UA Player з чотирма діями та синьо-золотим оформленням.
- Кнопка «Відкрити відео» має рухомий синьо-золотий перелив, поки головна сторінка відкрита; пульсація розміру завершується після трьох циклів. При виході анімації зупиняються, при поверненні запускаються знову; враховано системне вимкнення анімацій.
- Для нової установки за замовчуванням увімкнені темна тема й Super AMOLED; збережений вибір користувача при оновленні не змінюється.
- Виправлено дані UA Player у «Про застосунок»; під блоком «Проєкт» додано окрему «Подяку» розробнику Олександру (@levende) з посиланням на вихідний код.
- Прибрано квадратну підкладку логотипа.
- Виправлено відсутній дозвіл для системного перемикача «Керування всіма файлами».
- Головна сторінка адаптована до телефона й TV; налаштування дозволяють зміну орієнтації.
- Збережено оновлене ядро, Playlist API, старі контракти LampaUA і переклад тільки українською.

Пакет: `com.lampaua.player`. Версія **2.0.6**, збірка **26**.
Один APK для **arm64-v8a / armeabi-v7a**, сумісний сертифікат підпису.

APK цього релізу замінено оновленим оформленням без зміни номера версії та збірки. Якщо 2.0.6 уже встановлена, завантажте APK повторно й установіть поверх: автоматична перевірка не пропонуватиме ту саму версію.

Автоматична перевірка не замінює тестування відтворення й системного дозволу на реальному телефоні/Google TV.
