# UA Player 2.0.5

Оновлення ядра плеєра та інтеграції з LAMPA.

- Новий вкладений Playlist API: повний список одним запуском, стартова серія,
  назва серіалу окремо від серії, сезон/серія, IMDb/TMDB та зображення.
- Окремі джерела озвучення, варіанти якості та кліпи. Перемикання джерела
  зберігає позицію і стан паузи.
- Правила вибору аудіо та субтитрів за індексом, назвою, мовою і порядком
  доріжок; пріоритет ручного вибору; пам'ять озвучення для назв.
- Звіти про прогрес усіх відкритих елементів, журнал переходів,
  callback для LAMPA та відновлення API-сесії після перезапуску процесу.
- Облік заголовків запитів окремо для джерел плейлиста.
- Збережено старі формати запуску LampaUA, бренд UA Player та автопереклад
  тільки українською.

Пакет: `com.lampaua.player`. Версія: **2.0.5**, номер збірки: **25**.
Один release APK для **arm64-v8a / armeabi-v7a**, без окремого Legacy-файлу.
Сертифікат підпису сумісний із попередніми релізами.

## Перевірки та відомі обмеження

Локально пройдено 67 unit-тестів, lint без помилок і release build.
APK перевіряється на вирівнювання, метадані та підпис.
Реальне відтворення нового API на телефоні й Google TV ще потребує
перевірки: ці автоматичні тести не підтверджують відсутність усіх runtime-багів.

Підтримано основні aliases студій та зіставлення назв цілими словами.
Точна відповідність усім варіантам словника приблизно 900 студій,
згаданого в API, не підтверджена: повний набір даних недоступний
у перевірених відкритих джерелах.
