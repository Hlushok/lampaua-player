# UA Player 2.0.7

- Додано змішування декодованого об’ємного звуку у стерео для стереомаршруту з активним тунельним відтворенням. Стиснена пряма передача звуку не змінюється.
- Якщо пристрій відхиляє звуковий вихід PCM, плеєр один раз повторює відтворення без тунельного режиму для поточного відео. Це працює й після переходу всередині серії, а не лише на початку.
- Повторна спроба зберігає позицію та стан відтворення; загальне налаштування тунельного режиму не вимикається цим виправленням.
- Враховано зміну кількості аудіоканалів під час відтворення та захист від нескінченного повторення помилки.
- Збережено дизайн UA Player, налаштування, Playlist API й український автопереклад.

Пакет: `com.lampaua.player`. Версія **2.0.7**, збірка **27**.
Один APK для **arm64-v8a / armeabi-v7a**, сумісний сертифікат підпису.

Це точкове оновлення звукового відновлення, а не перенесення всіх нових можливостей ядра. Для підтвердження конкретного випадку Xiaomi TV потрібно повторити відтворення тієї самої доріжки та перехід до кінця серії на пристрої.
