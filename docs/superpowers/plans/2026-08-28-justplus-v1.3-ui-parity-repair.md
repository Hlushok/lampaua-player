# Just+ v1.3 UI and Subtitle Parity Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the proven Just+ v1.3 responsive player UI, control placement, settings hierarchy, and complete subtitle workflow in UA Player while keeping Ukrainian as the only auto-translation target.

**Architecture:** Treat `justplus-v13/master` at `21e1c334bc04b67afb4515b0e7d8dae50c962949` as the behavioral authority for layout, focus, grouping, visibility, side panels, and subtitle settings. Adapt those pieces into the current UA Player instead of replacing UA-specific playback recovery, LAMPA contracts, Watch Together, skip handling, branding, update routing, or signing. Put width/inset/control/subtitle decisions in small package-private policies with JVM tests, then make `PlayerActivity` and `SettingsActivity` render those decisions.

**Tech Stack:** Java 8, Android SDK 23+, Media3 1.11.0-beta01, AndroidX Preference 1.2.1, JUnit 4, Gradle/AGP, Android build-tools.

**Spec:** `docs/superpowers/specs/2026-08-28-justplus-v1.3-ui-parity-repair-design.md`

- Preserve UA Player branding, blue/gold styling, launcher page, LAMPA/LampaUA contracts, Watch Together, IPTV/playlists, recovery policies, server skip data, and session restore.
- Do not develop or touch Windows/QML/NSIS/Desktop integration.
- Do not copy donor package identity, updater, colors, signing, release metadata, or unrelated playback code.
- Follow red-green-refactor for every policy or resource contract: add the failing test, run it and confirm the intended failure, implement the smallest behavior, rerun the focused test, then run the neighboring suite.
- Use donor ordering and visibility as the default. A UA-only action may be inserted only in the matching donor semantic group and only when it is available.
- The auto-translation target is the constant Ukrainian (`ukr` for OpenSubtitles/cache and `uk` for the translation transport). Never restore a target-language picker or persisted target selection.
