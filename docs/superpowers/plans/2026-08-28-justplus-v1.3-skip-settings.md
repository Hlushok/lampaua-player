# Just+ v1.3 Skip and Settings Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Just+ v1.3 multi-source skip fallback, voting, session offset, and panel/settings behavior while keeping launcher/Lampac segments authoritative and retaining UA compact controls and styling.

**Architecture:** Normalize every source into one internal skip segment model, attach source priority/confidence, merge through a pure coordinator, then apply one session adjustment before timeline/button/auto/undo logic. UI remains an adapter over the model.

**Tech Stack:** Java 8, OkHttp/org.json, Android UI/Preferences, Media3 time bar, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-08-28-justplus-v1.3-parity-design.md`

## Global Constraints

- Source priority is launcher/LAMPA, then UA Lampac endpoint/cache, then Just+ direct sources.
- Keep the player independent of Alloha and Kodik.
- Session offset changes timeline, action, auto-skip, cancel, and undo consistently and does not persist across unrelated sessions.
- Keep UA compact pinned controls and grouped More menu; import no Just+ branding.
- Keep `com.lampaua.player`, `2.0.0 (20)`, LAMPA contracts, updater, and signing identity.
- Do not create a release tag, GitHub Release, or public release APK.
