# Just+ v1.3 Subtitle Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace UA Player's partial subtitle implementation with the complete Just+ v1.3 search, translation, hot-attach, timing, and dual-subtitle feature set under UA styling and LAMPA metadata contracts.

**Architecture:** Keep subtitle discovery, document transformation, timeline rendering, and UI integration as separate units. Adapt isolated Unlicense classes from Just+ v1.3, preserve UA's existing media identity and privacy guards, and expose Android UI only through `PlayerActivity` and `SettingsActivity`.

**Tech Stack:** Java 8, Android SDK 23+, Media3 1.11.0-beta01, OkHttp 5.3.2, org.json, JUnit 4, AndroidX Preference.

**Spec:** `docs/superpowers/specs/2026-08-28-justplus-v1.3-parity-design.md`

## Global Constraints

- Keep application id `com.lampaua.player`, version name `2.0.0`, and version code `20`.
- Keep UA navy/blue/gold resources and Ukrainian-first copy; import no Just+ branding.
- Preserve official `video_list.*`, legacy `lampaua.playlist_json`, per-episode subtitles, and current-result behavior.
- Translation target is user-selectable and defaults to Ukrainian.
- Provider/backend switches are hidden in normal builds; endpoint and API-key values never enter logs.
- Do not create a release tag, GitHub Release, or public release APK.
